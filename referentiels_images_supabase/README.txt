Images PNG individuelles prêtes pour Supabase Storage.

Dossiers : epis, epcs, risques, outillages, pieces_rechange.
Format : PNG 256x256, fond blanc.

Upload conseillé : conserver les mêmes chemins dans un bucket Supabase Storage (ex. referentiels).
Le fichier manifest.csv contient les chemins à enregistrer dans image_url.

Important : ces images proviennent des planches générées et sont découpées individuellement.
